# 2023级编译原理实验汇总

华南师范大学 2024-2025 学年第一学期编译原理实验汇总

## 注意事项

* 每年编译原理课程的实验会有一定的改动，请务必根据你当年的实验要求进行

* 本仓库是我之前所做的实验汇总，仅供参考，请勿照搬，直接套用后果自负（浴帘会狠狠扣分）
* 本实验汇总可能存在未发现的bug（有人发现的话就提个issue吧），个人能力和时间有限，实验代码存在缺陷还请各位多多包涵QAQ
* 23届一共5个实验，前两个的图形界面通过MFC实现，后三个实验则通过qt实现
